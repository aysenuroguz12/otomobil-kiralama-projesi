# C# Otomobil Kiralama Otomasyonu 

Bu proje, C# programlama dili kullanılarak geliştirilmiş, konsol veya form tabanlı (kullandığın altyapıya göre düzenleyebilirsin) bir araç kiralama yönetim sistemidir. Araç, müşteri ve kiralama işlemlerini organize etmek amacıyla tasarlanmıştır.

##  Özellikler
* **Araç Yönetimi:** Sisteme yeni araç ekleme, mevcut araçların durumunu (müsait/kirada) görüntüleme.
* **Müşteri Kaydı:** Kiralama yapacak müşterilerin bilgilerini sisteme kaydetme.
* **Kiralama İşlemleri:** Araçların müşterilere atanması ve süreç takibi.
* **Raporlama/Listeleme:** Kiralanabilir araçların listelenmesi.

##  Kullanılan Teknolojiler
* **Dil:** C#
* **Platform:** .NET Framework / .NET Core
* **Veri Yönetimi:** (Nesne Yönelimli Programlama - OOP / Listeler / Veritabanı freebase)
